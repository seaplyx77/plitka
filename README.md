# Плитка

Плиточный рабочий стол для Android в духе Windows Phone / Lumia: тёмная сетка, крупные плитки, папки и никаких Google-сервисов.

Написан вручную на Kotlin, **без единой сторонней библиотеки** (AndroidX отключён), **без интернета** и без рекламы.

- Пакет: `com.plitka.launcher`
- Минимальная версия: Android 8.0 (API 26)
- Целевая: Android 14 (API 34)
- Версия: 0.3

## Возможности

- **Плитки** — приложения, часы, «Все приложения», настройки. Ширину плитки можно растянуть от 1 клетки до всей ширины сетки.
- **Перетаскивание** — зажать плитку и потянуть; соседние плитки плавно разъезжаются, порядок сохраняется.
- **Папки** — зажать плитку над другой и подержать ~0,5 секунды. Внутри папки долгое нажатие убирает приложение, на столе — «Разобрать папку».
- **Счётчики уведомлений** — цифра на плитке, для папки — сумма по вложенным приложениям.
- **Настройки** — 3 или 4 колонки, скругление, прозрачность, акцентный цвет, скрытие названий и верхней панели.
- **Список приложений** — по алфавиту, свайп вправо с рабочего стола; долгое нажатие добавляет приложение на стол.
- **Первый запуск** — предложение выбрать «Плитку» домашним экраном.

## Приватность

Приложение не запрашивает **ни одного разрешения** — в манифесте нет даже `INTERNET`. Список плиток и настройки хранятся локально в `SharedPreferences`.

Доступ к уведомлениям («Плитка: счётчики уведомлений») выдаётся отдельно в настройках системы и используется только для подсчёта цифр на плитках. Передавать данные некуда: сетевого кода в проекте нет.

## Сборка

Нужны JDK 17 и Android SDK с Platform 34 и Build-Tools 34.0.0. Gradle wrapper уже в репозитории.

Если файла `local.properties` нет, укажите SDK через переменную `ANDROID_HOME` или создайте `local.properties` со строкой `sdk.dir=/путь/к/Android/Sdk`.

```bash
# Linux / macOS
chmod +x gradlew   # достаточно один раз после клонирования
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`

### Подпись release

Создайте файл `keystore.properties` в корне проекта (он в `.gitignore`) или рядом с папкой проекта:

```properties
storeFile=/путь/к/plitka-release.jks
storePassword=...
keyAlias=...
keyPassword=...
```

Затем:

```bash
./gradlew assembleRelease
```

Без этого файла release-сборка останется неподписанной — для локальной установки используйте debug-вариант.

## Установка

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Или скопируйте APK на телефон и откройте (понадобится разрешение «Установка неизвестных приложений»).

После запуска приложение само предложит стать домашним экраном. Передумать можно в любой момент: **Настройки → Сделать домашним экраном**.

```

├── MainActivity.kt            рабочий стол, меню плитки, первый запуск
├── data/
│   ├── Tile.kt                модель плитки и JSON
│   ├── TileStore.kt           хранение раскладки
│   ├── AppRepo.kt             список приложений, иконки, запуск
│   └── Prefs.kt               настройки
├── ui/
│   ├── TileBoardView.kt       сетка, перетаскивание, папки
│   ├── TileView.kt            отрисовка плитки, значок папки, счётчик
│   ├── FolderDialog.kt        окно папки
│   ├── AppListActivity.kt     список приложений
│   └── SettingsActivity.kt    настройки
├── service/
│   ├── NotiListener.kt        доступ к уведомлениям
│   └── Badges.kt              подсчёт счётчиков
└── util/
    ├── Home.kt                выбор домашнего экрана
    ├── SysBars.kt             прозрачные системные панели
    └── Ui.kt                  dp/sp-хелперы
```

## Планы

- изменение размера 2×2 и сетка 5–6 колонок;
- обои и несколько тем;
- анимации запуска приложений;
- экран «О приложении» и нормальная иконка.
